# IMAGES

Uploaded through the app, files land in one folder per item:

    images/characters/<id>/   images/locations/<id>/   images/research/<id>/
    images/scenes/<NNN_slug>/  images/framing/

Name files by what they show: hotel_randers_dining_1934.jpg, br52_front_flags.jpg.
You can also drop files here by hand and attach them from the "add an existing file" dropdown.
Removing an image from an item never deletes the file.
